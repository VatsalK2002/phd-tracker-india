# PhD Humanities Admissions Tracker - India 🎓

A clean, lightweight, mobile-first Progressive Web App (PWA) designed to track open, ongoing, and upcoming PhD application windows and seats in Humanities & Social Sciences across top Indian universities and institutes (Central Universities, IITs, TISS, etc.).

Created by **Vatsal Kumar (Archidyll)**.

---

## 🌟 Key Features
* **Zero Bloatware**: Super lightweight, loads in under a second on mobile networks.
* **Full iOS & Android Support**: Installs directly to your home screen with no app store downloads or developer fees.
* **Dynamic Deadlines & Countdowns**: Real-time day math calculation (e.g. "Only 6 days left!").
* **One-Tap Calendar Sync**: Exports standard `.ics` calendar events with automatic 24-hour reminder alarms for Apple Calendar, Google Calendar, and Outlook.
* **Offline Persistence**: Caches data locally so the tracker remains fully searchable with no internet access.
* **Email & SMS Alert Preferences**: Integrated notification subscription interface for critical updates.
* **Official Direct Portals**: Grounded links directly to verified university admission portals (JNU, Delhi University, University of Hyderabad, TISS, IITs, etc.).

## 🚀 How to Host on GitHub Pages
1. Fork or clone this repository.
2. In your repository settings, go to **Settings > Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your application will be live at `https://<your-username>.github.io/<repo-name>/`.
